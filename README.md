## The entry

A program that writes two lines to `/output/entry.txt`: line one warns the
writer's past self about one specific moment, and line two says in one
sentence why that moment mattered and what changed because of it.

> Don't quit the debate team in the hallway after losing the semifinal, while your coach is still holding the trophy list.
> That one angry minute cost you the captain's seat, and the year spent earning it back taught you never to decide while your hands are still shaking.

269 characters, two lines, one sentence each — inside the 1–280 character gate.

## Run

Requires Node 22:

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and prints it to stdout.
The output is fully deterministic: same bytes on every run.
